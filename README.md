### Sobre

API REST desenvolvida com **Node.js e Express** para gerenciamento completo de transporte escolar — cobrindo alunos, escolas, rotas, pontos de embarque, monitores, motoristas, veículos e manutenções.

Projeto Integrador I — Bacharelado em Ciência da Computação · UNOESTE

---

### Módulos

- Alunos e responsáveis (com vínculos de parentesco)
- Escolas e pontos de embarque
- Rotas de transporte e inscrições por rota
- Monitores e motoristas
- Veículos e controle de manutenção
- Autenticação de usuários

---

### Como rodar

```bash
git clone https://github.com/paulomcfm/ProjetoDECEL-backend
cd ProjetoDECEL-backend
npm install
npm start
```

> Configure as variáveis de conexão com o PostgreSQL antes de executar.
